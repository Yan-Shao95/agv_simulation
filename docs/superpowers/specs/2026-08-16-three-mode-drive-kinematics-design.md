# AGV 三模式驱动运动学设计

## 目标

修正四差动驱动总成 AGV 在直行、横移、自转及带转向运动之间切换时的舵角和轮速行为。系统继续使用标准 `/cmd_vel` 接口和 `teleop_twist_keyboard` 键位，并确保所有舵角目标的绝对值不超过 90°。

## 模块编号与位置

模块位置沿用当前定义：

| 模块 | 位置 | 坐标（m） |
|---|---|---|
| 1 | 左前 | `(0.45, 0.325)` |
| 2 | 右前 | `(0.45, -0.325)` |
| 3 | 右后 | `(-0.45, -0.325)` |
| 4 | 左后 | `(-0.45, 0.325)` |

## 运动学模式

### 纯纵向

四组舵角均为 0°。正轮速表示前进，负轮速表示后退。

### 纯横向

横移使用固定舵角符号：

```text
模块：       1      2      3      4
舵角：     -90°   +90°   -90°   +90°
左移轮速：   -      +      -      +
右移轮速：   +      -      +      -
```

横移舵角符号与逆时针自转时各模块的优化舵角符号保持一致。

### 纯自转

先依据模块位置计算绕车体中心的切线速度方向，再使用等价舵角和反向驱动将舵角限制到 `[-90°, +90°]`。

逆时针自转目标约为：

| 模块 | 舵角 | 驱动速度符号 |
|---|---:|---:|
| 1（左前） | `-54.2°` | 负 |
| 2（右前） | `+54.2°` | 正 |
| 3（右后） | `-54.2°` | 正 |
| 4（左后） | `+54.2°` | 负 |

顺时针自转生成相反的车体角速度，并同样保证舵角绝对值不超过 90°。

### 带转向运动

纵向或横向速度与角速度同时存在时，根据瞬时旋转中心计算每组目标速度向量，再对每组执行 `±90°` 舵角优化和轮速反向。这样支持直行转弯、倒车转弯和横移转向。

### 零命令

零速度命令只将驱动速度降为零，保持最后有效舵角，不强制四组回到 0°。

## 模式切换控制

`ModuleAngleController` 使用整车统一对正条件，而不是让四个模块分别决定是否驱动：

1. 收到目标并判断目标角是否发生明显变化。
2. 任一模块超出退出容差时，四组驱动一起减速至零。
3. 四组执行舵向调整。
4. 所有模块进入就绪容差后，四组同步按加速度斜坡恢复驱动。
5. 使用进入和退出双容差，避免临界角附近反复启停。
6. 大角度误差、命令超时或控制模式切换时立即停止驱动。

控制器不得出现部分模块驱动、部分模块仍在对舵的状态。

## ROS 接口与键盘

保持现有接口不变：

- 输入：`/cmd_vel`
- 总成目标：`/drive/module_target`
- 对正后的总成命令：`/drive/module_velocity_target`
- 最终轮速：`/wheel_velocity_controller/commands`

标准键位：

- `i / ,`：前进、后退
- `Shift+J / Shift+L`：左横移、右横移
- `j / l`：逆时针自转、顺时针自转
- `u / o / m / .` 及其 Shift 组合：带转向运动
- `k`：停车

键盘节点以 10 Hz 重发当前命令，以满足 0.5 秒命令看门狗。

## 错误与安全行为

- 非有限速度输入不得进入运动学计算。
- 命令超时立即发布八轮零速。
- 模式切换先发布八轮零速。
- 任一模块出现大角度误差时整车停止驱动并继续对舵。
- 停车后保持舵角，下一次运动按完整对正流程恢复。

## 自动测试

测试覆盖：

- 前进和后退四组舵角均为 0°。
- 左横移舵角为 `[-90°, +90°, -90°, +90°]`，轮速符号为 `[-, +, -, +]`。
- 右横移保持相同舵角并反转轮速。
- 顺、逆时针自转舵角绝对值不超过 90°。
- 逆时针自转时左前向右转、左后向左转。
- 组合运动满足各模块瞬时速度向量。
- 任一模块未对正时四组驱动均为零。
- 全部对正后四组同步缓启动。
- 零命令保持最后舵角。
- 超时命令立即停车。

## 仿真验收

依次执行：

1. 直行与后退。
2. 左右横移。
3. 横移后恢复直行。
4. 顺、逆时针自转。
5. 自转后切换横移。
6. 前进、后退和横移过程中的圆弧转向。

每一步检查四组舵角、八轮目标速度、实际关节状态和轮式里程计，确认无永久等待、符号混乱或部分模块提前驱动。
